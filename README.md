# Acadly - Tuition & Coaching Management App

Acadly is a multi-institute mobile platform built with **Expo**, **React Native**, **TypeScript**, and **Supabase**, designed to manage teachers, students, parents, batches, attendance, study materials, video lectures, assignments, examinations, fees, and reports.

---

## 🎯 Product Overview

Acadly provides multi-tenant, role-based experiences tailored for four key user roles:

- 🏫 **Institute Admin**: Manages institute settings, teachers, students, batches, fee structures, and analytics.
- 👨‍🏫 **Teacher**: Manages assigned batches, attendance, video lectures, study materials, assignments, and exams.
- 🎓 **Student**: Accesses enrolled batches, lecture recordings, notes/PDFs, attendance records, assignments, and exam results.
- 👨‍👩‍👦 **Parent**: Tracks linked children's daily attendance, assignments, exam reports, and fee dues.

---

## 🛠️ Technology Stack

| Layer | Technology |
|---|---|
| **Mobile Application** | Expo + React Native |
| **Language** | TypeScript |
| **Routing / Navigation** | Expo Router |
| **Styling** | NativeWind (Tailwind CSS) |
| **Backend & Database** | Supabase (PostgreSQL + RLS) |
| **Authentication** | Supabase Auth |
| **Storage** | Supabase Storage (PDFs, docs) |
| **Forms & Validation** | React Hook Form + Zod |
| **State Management** | React Context API / useState |
| **Notifications** | Expo Notifications |
| **Payments** | Razorpay (Phase 4) |

## 🗺️ 5-Phase Development Roadmap

- [ ] **Phase 1: UI/UX Design System & Project Setup**
  - Design tokens, reusable components, Expo Router navigation scaffolding, and NativeWind styling setup.
- [ ] **Phase 2: Authentication & Multi-Institute Management**
  - Supabase Auth, institute onboarding & join codes, role-based permissions (RLS), batch management.
- [ ] **Phase 3: Core Academic Workflows**
  - Attendance marking, study material repository, video lecture links, assignments & submissions, examinations & grading.
- [ ] **Phase 4: Fees, Push Notifications & Analytics**
  - Fee plans, tracking & receipts, Expo push notifications, admin reporting & charts, Razorpay integration.
- [ ] **Phase 5: Testing, Security & Release**
  - RLS audits, edge case handling, EAS Build setup, Play Store & App Store deployments.
