## 🎨 Theme & Token Specifications

- **Surface System**: High-clarity light canvas with subtle container steps (`surface-container-low`, `surface-container-lowest`, `surface-container-high`).
- **Typography**: Inter / Modern sans with hierarchical text scales (`headline-lg`, `headline-md`, `headline-sm`, `label-md`, `body-md`, `tabular-numeric`).
- **Primary Brand Color**: Deep Slate / Onyx (`#000000` / `#131b2e`).
- **Interactive Secondary Color**: Electric Royal Blue (`#0051d5` / `#316bf3`).
- **Academic Vitals Emerald**: Forest Teal (`#069669` / `#85f8c4`).
- **Urgent / Dues Indicator**: Soft Crimson Alert (`#ba1a1a` / `#ffdad6`).
